# MEDMAP 3D — іске қосу нұсқаулығы (XAMPP, доменсіз)

MEDMAP 3D — интерактивті 3D адам денесі арқылы денсаулық туралы өтінім жіберуге, оны дәрігер мен әкімші қарауға арналған медициналық ақпараттық платформа. Барлық деректер XAMPP құрамындағы MySQL-де сақталады.

> Демонстрациялық жоба: барлық деректер ойдан шығарылған. Платформа диагноз қоймайды және дәрі ұсынбайды.

## 1. Не қажет

| Бағдарлама | Қайдан |
|---|---|
| XAMPP (Apache + MySQL) | https://www.apachefriends.org — әдепкі жол `C:\xampp` |
| Node.js 20 немесе жаңасы | https://nodejs.org (LTS) |

PHP-ге қайта жазылған жоқ: сайт React + Node.js (Express) + MySQL (Prisma ORM) арқылы жұмыс істейді. Apache дайын сайт файлдарын береді, ал Node.js сервері API-ді (4000 порт) өңдейді.

## 2. Іске қосу — бір батырма

1. Жоба папкасындағы **`START_MEDMAP.bat`** файлын екі рет басыңыз.
2. Скрипт өзі:
   - XAMPP **MySQL**-ді тексеріп, өшірулі болса қосады;
   - бірінші рет болса `server\.env` жасап, `npm install` орындайды;
   - деректер базасын (`medmap3d`) жасап/жаңартады, бос болса демо деректерді енгізеді;
   - сайтты `C:\xampp\htdocs\medmap3d` папкасына көшіреді;
   - XAMPP **Apache**-ты қосады;
   - Node.js API серверін фондық режимде қосады;
   - браузерде сайтты ашады.
3. Сайт мекенжайы: **http://localhost/medmap3d/**

Егер 80 порты бос болмаса (Apache қосылмаса), сайт **http://localhost:4000/medmap3d/** мекенжайынан ашылады — скрипт оны өзі анықтайды.

**Тоқтату:** `STOP_MEDMAP.bat` (Node серверін тоқтатады; XAMPP Apache мен MySQL басқа жобалар үшін қосулы қалады — оларды XAMPP Control Panel-ден тоқтатуға болады).

## 4. Gmail арқылы хат жіберу (міндетті емес)

Тіркелу кезіндегі растау коды, құпиясөзді қалпына келтіру сілтемесі және өтінім туралы хабарламалар Gmail SMTP арқылы жіберіледі.

1. Google аккаунтыңызда **2 қадамды растауды** қосыңыз.
2. https://myaccount.google.com/apppasswords бетінде **App Password** (16 таңбалы қолданба құпиясөзі) жасаңыз. Кәдімгі Gmail құпиясөзін қолданбаңыз.
3. **`SETUP_EMAIL.bat`** іске қосып, Gmail мекенжайы мен App Password енгізіңіз (құпиясөз экранда көрінбейді, тек `server\.env` файлына жазылады — бұл файл GitHub-қа жіберілмейді).
4. `STOP_MEDMAP.bat`, содан кейін `START_MEDMAP.bat`.
5. Админ панелі → **Email жүйесі** → «SMTP байланысын тексеру» және «Тесттік хат жіберу».

SMTP бапталмаса да сайт толық жұмыс істейді: **демо режимде** растау коды мен қалпына келтіру сілтемесі экранда көрсетіледі, ал барлық хаттар «Email жүйесі» журналына «Жіберілмеді (SMTP жоқ)» деп тіркеледі.

## 5. Негізгі сценарий (оқытушыға көрсету үшін)

1. **Пациент**: Тіркелу → Gmail-ге келген 6 таңбалы кодпен растау → 3D денеден аймақты басу → «Өтінім жіберу» → форма (аты-жөні, email, телефон, аймақ, сипаттама, басталған күні, ұзақтығы, қарқындылығы, қосымша ақпарат, файл) → «Өтінімді жіберу». Өтінім нөмірі (мыс. `APP-000010`) шығады, MySQL-ге сақталады.
2. **Әкімші**: «Өтінімдер» бөлімінде жаңа өтінім ең жоғарыда, қызыл санауышпен. Ашу → толық ақпарат → мәртебені өзгерту (Жаңа өтінім / Қаралуда / Қабылданды / Аяқталды / Қабылданбады) → іздеу, күні бойынша сұрыптау, мәртебе бойынша сүзгі, өшіру.
3. **Дәрігер**: рұқсат берген пациентті ашады → 3D картада аймақтар → өтінім мәртебесін өзгертеді, қорытынды/жазба/тағайындау қосады.
4. **Пациент**: «Өтінімдерім» бөлімінде мәртебе мен дәрігер жауабын көреді, хабарламалар келеді.

## 6. Деректер базасы (phpMyAdmin)

- phpMyAdmin: http://localhost/phpmyadmin → `medmap3d` базасы.
- Негізгі кестелер: `users`, `patient_profiles`, `doctor_profiles`, `pharmacy_profiles`, `symptom_reports` (өтінімдер), `report_attachments`, `body_areas`, `medical_records`, `doctor_notes`, `medications`, `prescriptions`, `patient_consents`, `notifications`, `activity_logs`, `email_verifications`, `password_resets`, `email_logs`.
- Қолмен импорт: **`DATABASE_SETUP.sql`** (phpMyAdmin → Импорт). Базаны демо күйіне қайтару: `npm run db:seed`.

## 7. Қауіпсіздік

- Құпиясөздер **bcrypt** (12 раунд) арқылы хештеледі; растау коды мен қалпына келтіру токені HMAC-SHA256 хеші түрінде ғана сақталады.
- Растау коды 10 минут, қалпына келтіру сілтемесі 30 минут жарамды және бір рет қолданылады; қайта сұрау саны шектелген.
- Расталмаған email-мен кіруге болмайды; рөлге сәйкес кабинетке бағыттау; httpOnly cookie сессиясы.
- Дәрігер тек рұқсат берген пациенттің деректерін көреді; пациент тек өз өтінімдерін көреді.
- Бір өтінімнің қайталануынан қорғау (idempotency кілті), серверде деректерді тексеру (Zod), файл түрі мен мазмұнын тексеру, әрекеттер журналы.
- SMTP құпиясөзі кодта да, админ панелінде де, логтарда да көрсетілмейді.
